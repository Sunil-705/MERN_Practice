# Backend CRUD API with Express.js

A simple RESTful API built using **Node.js**, **Express.js**, and **MongoDB** that demonstrates CRUD (Create, Read, Update, Delete) operations.

## 🚀 Features

- Create new records
- Read all records
- Read a single record by ID
- Update existing records
- Delete records
- RESTful API architecture
- MongoDB database integration
- Error handling and validation

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Postman (API Testing)
